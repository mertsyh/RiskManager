# Risk Manager

A browser-based risk management game built with Vue 3 + Vite.

## How to Play

You are a risk manager at **Ispanak Ventures**, tasked with shipping **PROJECT: NEON** — a cloud payments & analytics platform. Risks appear one by one, and you must classify each one correctly before it escalates.

Each risk is classified by its **Probability × Impact** into one of four categories:

| Animal | Strategy | When to use |
|--------|----------|-------------|
| 🐯 Tiger | **Avoid** | High probability, high impact |
| 🐊 Alligator | **Transfer** | High probability, low impact |
| 🐶 Puppy | **Mitigate** | Low probability, high impact |
| 🐱 Kitten | **Accept** | Low probability, low impact |

Classify risks correctly to progress through the 7-stage risk management cycle. There's no deadline — but every day counts. Ship the project as fast as possible to top the leaderboard.

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Deploys to GitHub Pages via `gh-pages`.
